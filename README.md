# RelativeShortcutWindows
Create Relative Shortcut on windows simply


## Requierements
Windows XD
AutoHotkey v2.0

## Instalation
Get the two files in the same folder but where you want.

double click on the .ahk to activate the shortcut.

For an automatical execution add it to be lnch at the start of Windos:

Windows+R 
Enter : "shell:startup"
click "ok"

then, add a shortcut of the .ahk


## Use
ctrl + d + c : to copy the file
ctrl + d + v : to paste relative link
